## What it is

lelantos is an AI powered website that uses advanced algorithms and API keys from serp and Wikipedia in order to connect two people through personal connections. This program uses the 6 degree separation theory that every person is connected to every other person by at most 6 degrees of separation.

## How to run it
Run python final_project.py in the terminal and if needed to pip install requests

## How it works
It first tries to find biographies or autobighraphies written by the person then tries to find people who were together with this person and when it does find it validates using GOOGLE AI to check if they actually met, and then this proccess repeats, lastly it creates a web to show the path of how they met.
